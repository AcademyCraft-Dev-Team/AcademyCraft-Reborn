# 测试维护

测试按生产代码包组织：`src/test/java` 和 `src/test/kotlin` 覆盖模组逻辑，`src/editorTest` 覆盖独立编辑器。完整构建还会执行类指针兼容性专用 JVM 测试和 API 示例检查。

新增测试优先覆盖可观察行为、异常边界、状态清理和兼容性回归。同一行为尽量放在已有测试类中，避免复制同一组断言。只确认枚举成员存在、复制调参常量或搜索源码字符串的临时检查，通常无需长期保留；协议、持久化格式和跨模块资源约定仍应保持明确的兼容性检查。

删除前确认无独有行为覆盖和共享依赖；有独有边界检查时先合并。历史命名或文件较短不代表测试无用。包级空值注解、测试夹具及 golden 资源不是可随意删除的空文件。

2026-09-22 清理前的完整备份、逐文件处理清单及恢复步骤见 [测试归档](../../archives/tests/2026-09-22/README.md)。归档不参与测试编译；保留压缩包，不将历史源码重新放进 source set。
