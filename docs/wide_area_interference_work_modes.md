# 广域干涉：RTS 工作系统

## 实现范围

1. 相机使用指数缩放、绕焦点旋转、平移和独立高度调整，解除原先 8–64 格距离限制；相机位置在视锥计算前生效，远裁剪和距离雾随相机距离扩展，实体渲染距离以观察焦点计算。
2. 框选改为与世界方块轴平行的半透明范围、网格与边线；实体碰撞箱相交判定和实时高亮共用同一范围。工作指令提交预览对应的整数方块边界。
3. 底部统一“工作”入口，右侧子面板配置模式、范围、任务、过滤与物流点。
4. 工作由服务端持续调度，接管 Goal / Brain 的自主行为并保留受控寻路；订单、暂停状态和携带物资保存到世界数据。
5. 空装备提供默认铁质效果，实际装备优先，不创建可掉落的虚拟装备。

布局和交互参考 [RTSbuilding](https://github.com/Hcrab/RTSbuilding)；模式配置参考 [Touhou Little Maid](https://github.com/TartaricAcid/TouhouLittleMaid)。代码和界面资源独立实现，无须安装这两个模组。

## 操作

| 操作 | 效果 |
| --- | --- |
| 滚轮 | 围绕 RTS 画面中心缩放；距离保留 0.5–16384 格数值保护 |
| Shift / 空格（按住） | 连续拉近 / 拉远 |
| 右键拖动 | 以 RTS 画面中心地面点为转轴旋转；拖动期间停止平移惯性 |
| 中键拖动 / WASD | 平移 |
| Q / E | 水平旋转 |
| Alt + 滚轮 | 调整焦点高度 |
| F / Home | 聚焦首个选中实体 / 返回玩家位置 |
| 左键拖动 | 绘制实体框选范围，实时预览即将选中的实体 |
| Ctrl + 框选 | 追加选择 |
| 绘制时滚轮 / Alt + 滚轮 | 调整范围高度 / 垂直偏移 |
| Alt + 左键拖动 | 预览并隐藏遮挡方块；Alt + 右键恢复 |
| Esc | 取消当前绘制，再关闭工作面板，最后退出界面 |

相机距离与服务器指令距离分别计算。新指令仍受 96 格权限范围限制；工作区域每轴最多 32 格、总体最多 4096 格。远处未加载的区块不会因相机移动强制加载。

## 工作配置

选择实体 → 工作 → 范围页绘制区域 → 配置模式和任务 → 应用并开始。

绘制结束后自动打开顶点编辑：顶点 A、B 各有 X/Y/Z 三个整数输入框，表示包含边界方块的两个对角顶点；每个坐标旁的 + / − 可逐格调整。合法编辑立即更新世界预览，跨越对角点时自动归一化最小 / 最大坐标。空值、非整数、超出世界高度 / 边界、单轴超过 32 或总体超过 4096 的修改不应用，保留上次有效预览并显示错误。修改完成后“应用并开始”才下达或替换订单；“返回范围 / 物流设置”可继续重绘或配置箱子。

“读取首个选中实体的现有订单”显式加载该实体的配置；应用会更新所有选中实体。暂停保留 AI 接管，继续恢复原订单，取消解除工作并返还携带物资。

| 模式 | 行为与过滤对象 |
| --- | --- |
| 资源采掘 | 开采允许破坏且工具等级足够的方块；跳过方块实体；过滤方块 |
| 农业 | 收获成熟作物、翻耕区域内的泥土 / 草方块、播种和补种；过滤作物方块 |
| 伐木 | 采伐区域内原木；过滤方块 |
| 甘蔗 / 竹子 | 保留底部植株，采集其上方部分；过滤方块 |
| 清草 / 清雪 / 灭火 | 清理匹配的植被、雪层和火；过滤方块 |
| 剪毛 | 接近可剪毛成年动物并收集产物；过滤实体 |
| 挤奶 | 对成年牛使用实际空桶；过滤实体 |
| 喂养繁殖 | 使用动物接受的实际食物；过滤实体 |
| 拾取搬运 | 拾取区域内可拾取物品并送往输出点；过滤物品 |

过滤允许完整 ID 或 `#标签`，以逗号、分号或空白分隔。允许列表为空表示全部，排除列表为空表示不排除。标签使用当前模式对应的方块、实体或物品注册表。最多 32 个条目，每个最长 128 字符。

补给箱提供种子、饲料、空桶和需要替换的实际工具；工人实际走到箱子附近取用。输出箱接收产物；容量不足、缺少材料或路径受阻时保留订单并等待重试。农业保留少量种子用于后续播种。单次任务完成或手动取消时，剩余物资交还控制者。

农业范围须包含目标植物格；需要翻耕时还须包含其下方土壤。农业绘制默认覆盖土壤和其上方两层。任务页分别控制循环、收获、播种 / 补种。

## 默认铁质装备

- 空手采掘按方块选用铁镐、铁斧、铁锹或铁锄的效果；保留铁质采集等级，不能采集要求钻石工具的黑曜石。
- 空手允许翻耕与剪毛，分别使用铁锄和剪刀效果。
- 空头、胸、腿、脚栏分别补充 2、6、5、2 点护甲；该栏有装备时不叠加默认护甲。
- 空手接管实体增加铁剑的 5 点攻击加成；原本缺少攻击属性的被动实体在通用强制近战路径中按 6 点基础伤害处理。
- 真实手持物品优先，保留附魔、采掘等级并正常消耗耐久；拿着不适用工具时可配置补给箱提供合适工具。
- 虚拟效果不占槽、不进入背包、不产生装备掉落；解除接管时清除临时属性。
- 种子、饲料、空桶等消耗材料仍需实际提供，工作会按实际用量消耗。

公共扩展接口为 `ControlledEquipment`、`WorkSettings`、`WorkSelection`、`GroupControlCommand.Work`、`GroupControlApi.pauseWork/cancelWork`，供能力、实体适配器和后续精密操作系统复用。

## 持续工作与边界

订单没有短期技能超时，工作组共享候选目标和领取队列。缺少成熟目标时定期扫描，路径受阻时延后重试，高优先级控制抢占时等待恢复。

任务页新增三种挖掘距离策略：

- **自适应（默认，含旧订单）**：先就近挖掘；无可达站位、寻路失败或持续无进展时，该工人转为从当前稳定位置完成区域挖掘，避免继续追逐坑底目标。
- **区域内不限**：无需走到目标旁即可挖掘；仅操作订单范围内已加载、允许开采且工具等级足够的方块。
- **仅近身**：保留 3.5 格挖掘距离；不可达目标进入重试队列，不误报完成。

区域挖掘优先处理上层、暴露表面，并通过作业面分配减少工人聚集。每个目标只能由一名工人领取。工具不足、权限拒绝、区块卸载和寻路失败分别记录，暂时跳过受阻目标继续处理其它方块；暂停或取消工人时释放其领取目标。最后复查整个区域，待处理、执行中和受阻目标均为零才允许单次订单完成。界面显示首个选中工人所属工作组的本轮已完成、剩余与受阻数量；加载恢复后重新核对世界状态，计数从当前加载轮次重新开始。

区域内不限距离不会取消订单范围、工具等级、采掘时间、耐久、权限或加载限制，也不改变实际补给和输出流程。掉落先沿现有空间存储路径收集，未收集的产物按物品堆叠缓存，避免每次掉落占用一个缓存槽。输出满时仍会明确等待物流处理。任务结束时按真实容量返还背包，创造模式背包满也不会销毁剩余产物，溢出物品按正常掉落返还。

控制者在线且工人区块正常加载时可持续工作，离开 GUI 或控制者切换维度不会主动取消订单。控制者离线、死亡或工人卸载时保存并挂起；重新上线且有既有控制记录的工人加载后恢复。同区域同配置的工人恢复为共享工作组。工人死亡或取消订单后删除对应订单。

当前不提供离线模拟、强制区块加载或远程区块订阅；任意第三方实体的特殊 AI 仍需遵循实体控制适配接口。

## 验证

- 完整单元测试 1678 项通过：包含选择几何、工作配置与过滤、命令包编解码。
- 本轮心理掌握游戏回归 34 项中 33 项通过；`impression_internal_anger_whitelist` 在第 7 刻的断言失败，独立复测通过。上一轮批量运行不稳定的 `impression_riding_flight` 也已独立复测通过。9 项工作场景均通过。
- 开发版与发布版 `build` 均通过；完整回归中的上述不稳定用例保留记录。
- 游戏测试：空手采石及掉落数量、无锄翻耕与准确种子消耗、无剪刀剪毛、虚拟装备与真实装备切换、取消后的临时属性清理。
- 持久化测试：订单编解码、暂停仍接管、运行时清理后恢复、继续和取消。
- 耐久测试：64 个实体持续接管 72000 游戏刻（一个模拟小时）。
- 本轮 `runClientDev` 已加载模组，但进入测试世界后在 `VectorReflectionRuntime.closeTemporalImmunity → TemporalRuntime.requireServerThread` 调用链发生 `Temporal state may only change on the server thread` 异常。启动时还记录了资源重载的 `Missing uniform Globals`。这两处实现未在本轮修改。Windows 窗口检查工具也因 sandbox ACL 初始化失败；镜头手感、输入框实机操作、多 GUI 缩放和明暗背景视觉验收尚未完成。详情保留于本地 `build/mining-client-startup.log`。
