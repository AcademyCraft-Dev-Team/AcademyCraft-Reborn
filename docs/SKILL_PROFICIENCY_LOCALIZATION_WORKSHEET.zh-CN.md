# 技能熟练度本地化人工调整工作表

## 使用说明

本文按当前 `Skills.java` 注册表、技能源码和中英语言文件整理，供继续人工调整本地化文本使用。

- 共覆盖 92 个现行技能：85 个能力分类技能和 7 个 Level0 公共技能。
- 85 个能力分类技能均应具有 `1000 / 2000 / 3000` 三档文本，共 255 个键。
- 熟练度键统一为 `skill.academy.<技能 ID>.proficiency.<1000|2000|3000>`。
- `↓` 表示按下，`↑` 表示松开。默认按键可以在客户端设置中重绑，最终文案宜同时写动作名称，不要只依赖字母键。
- 状态：`✅` 与当前源码一致；`⚠` 文本、数值或操作说明仍需调整；`⏳` 描述保留但源码尚未实现，语言文件已附“（暂未完成）”。
- 区域传送已合并为唯一技能 `area_teleport_select`，数据终端中的五个操作键均归入同一个技能设置条目。

## 人工改写建议

1. 操作文案优先采用“动作名称 + 默认按键”，例如“按住自身传送键（默认 `R`），滚轮调距，松开施放”。这样重绑按键后文本仍可理解。
2. 返程、二段触发、标记消费、潜行、普通攻击和滚轮等输入条件必须写进 3000 档文本；只写“可再次施放”通常不足以让玩家复现效果。
3. 服务器配置可覆盖部分 CP、范围和策略开关。对可配置数值，宜写成百分比或“默认值”，避免把配置默认值描述成不可变规则。
4. 对 `❓` 项不要仅改文案掩盖缺失实现：应先决定补实现，还是把该档改成源码已经存在的效果。
