# 非通用技能熟练度里程碑方案

## 1. 文档范围

本文以当前 `Skills.java` 的注册结果为准，为 7 个非 Level0 能力类别的 **85 个非通用技能**设计熟练度达到 `1000 / 2000 / 3000` 时的额外效果。Level0 的 7 个公共脑开发技能不在本方案范围内。

| 类别 | 技能数 |
| --- | ---: |
| Aeromanip 气动操纵 | 15 |
| Accelerator 矢量操纵 | 14 |
| Electromaster 电气操纵 | 16 |
| Meltdowner 原子崩坏 | 10 |
| Teleport 空间移动 | 16 |
| Darkmatter 未元物质 | 7 |
| Mentalout 心理掌握 | 9 |
| **合计** | **87** |

## 2. 通用结算规则

1. 三档效果为里程碑奖励：熟练度达到阈值后永久生效，且不同档效果累计。
2. 若后档写有“总计”，则该项数值取后档给出的总值，不再与前档重复相加。例如 `1000：消耗 -10%`、`2000：消耗总计 -15%`，最终为 `-15%`。
3. 未写“总计”的新机制会保留前档效果。范围、持续时间等数值先应用服务端配置，再应用熟练度倍率。
4. “消耗降低”同时适用于该技能明确列出的施放、持续和维持成本，但不降低其他技能、召唤物或额外目标的独立成本；表中另有说明时除外。
5. 伤害加成只作用于该技能自身的普通技能伤害，不放大处决、强制终结、最大生命百分比、真实生命或其他特殊伤害段，除非表中明确说明。
6. PvP 中的控制持续时间、百分比伤害与处决仍服从服务器上限；熟练度不能绕过保护事件、友军判断、无敌、免疫标签、区块加载与方块破坏权限。
7. 里程碑必须根据原始熟练度直接判定。现有 `Skill#getLevelForProficiency` 的等级分界是 `750 / 1500 / 2250`，不能用它代替本方案的 `1000 / 2000 / 3000` 分界。`maxSkillLevel(0)` 的技能也仍可获得里程碑奖励。

## 3. 已确定的矢量防御规则

矢量反射与矢量偏移的伤害处理 CP 占用采用离散档位，不在相邻阈值间线性插值。倍率以“本次实际反弹或免疫的伤害值”为基数，替换当前的 `1 CP : 1 伤害` 逻辑。

| 熟练度区间 | CP 占用倍率 | 示例：处理 10 点伤害 |
| --- | ---: | ---: |
| `[0, 1000)` | 伤害值 ×2 | 20 CP |
| `[1000, 2000)` | 伤害值 ×1 | 10 CP |
| `[2000, 3000)` | 伤害值 ×0.5 | 5 CP |
| `3000` | 伤害值 ×0.5 | 5 CP |

该规则只替换伤害反弹/免疫的动态占用，不取消技能原本的开关维持占用，也不改变投射物改向、减速场等非伤害机制。为避免改变已确认设计，下面两项不再附加其他熟练度奖励。

| 心灵潜入 `mental_intrusion` | 远程观察目标而不移动或控制它；观察玩家有时限并占用 CP。 | 观察占用总计 `-10%`。 | 会话最大距离由 96 增至 128 格；目标跨出普通选取距离后仍可维持。 | 观察界面显示目标生命、护甲、主要状态效果和手持物；观察玩家的最长持续时间 `+50%`，仍受冷却限制。 |
| 意识接管 `mental_takeover` | 接管清单内玩家的移动、视角和当前手动作，目标可持续挣扎解除。 | 会话占用由 100 降至 90 CP。 | 目标的挣扎进度获取速度降低 25%，受到真实伤害时仍立即按原规则中断。 | 解锁经服务端验证的副手使用与快捷栏切换；每秒最多切换一次，禁止打开容器、丢弃物品和修改背包。 |
| 感官扭曲 `sensory_distortion` | 观察期间从目标的视线、仇恨、渲染和直接交互中隐藏施术者。 | 维持占用总计 `-10%`。 | 同时抑制施术者产生的普通脚步声、游戏事件振动和非攻击粒子；伤害与方块交互仍会暴露。 | 施术者离开目标视野时留下 3 秒虚假感知残影，使自然索敌停留在旧位置；显式攻击目标不受残影误导。 |
| 指挥定位 `command_positioning` | 命令清单成员移动到方块外侧或持续跟随指定实体。 | 每目标路径占用由 10 降至 9 CP。 | 指令距离由 64 增至 80 格，路径重算间隔 `-25%`。 | 点地指令会让清单成员按体型自动组成环形队列，避免挤在同一方块；Boss 保留自身移动合同。 |
| 精密操作 `precision_operation` | 编辑并运行四个服务端校验的无环心理操作程序，各持续行动可独立设时或永久维持。 | 程序内所有按目标持续占用 `-10%`。 | 同时运行两个以上槽位时，共享目标的重复感知/路径节点只结算一次，占用归属最早启动槽位。 | 解锁有界条件分支节点，可按生命比例、距离、目标类型与状态效果选择两条分支；仍禁止循环，单次程序节点与执行预算不提高。 |

## 11. 实现与验收建议

### 11.1 推荐实现入口

- 增加独立的熟练度里程碑解析器，例如 `tierForProficiency(float)`，返回 `0/1/2/3`，边界固定为 `0/1000/2000/3000`。
- 不修改现有 `Skill#getLevelForProficiency`，避免影响原有技能等级、旧存档迁移与既有数值公式。
- CP 折扣、范围倍率、持续时间和特殊机制统一从服务端读取熟练度；客户端只负责展示和预测。
- 对矢量反射/偏移增加共用的伤害处理倍率函数，并让普通伤害、线性攻击、持续攻击和异常伤害入口使用同一结算结果。
- 将里程碑数值放入可配置表时，服务器配置应覆盖本文默认值，但必须保持有限数、非负、范围上限与体积上限校验。

### 11.2 必测边界

1. 分别以 `999.99 / 1000 / 1999.99 / 2000 / 2999.99 / 3000` 验证三档切换，无线性插值和浮点越界。
2. 矢量反射与矢量偏移处理 10 点伤害时，动态占用必须分别为 `20 / 10 / 5 / 5 CP`；CP 不足时不得产生免费全免或超额反弹。
3. 验证里程碑折扣与公共计算效率、服务端配置、永久占用、限时占用的结算顺序，确保退出技能、死亡、换维度和断线后完整释放。
4. 所有新增范围技能必须继续排除未加载区块，并限制每 tick 实体、方块、投射物和网络同步预算。
5. 区域传送的旋转、镜像和交换模式必须覆盖方块实体、流体、计划刻、载具链以及失败回滚；不支持的方块状态应在扣费前拒绝。
6. 所有复制、返还、分裂、连锁与召唤效果必须保持原施术者和技能伤害归属，防止重复经验、重复熟练度或无限返还 CP。
7. 对玩家、Boss、盟友、驯服生物和保护区分别进行行为验收，确认本文列出的减半、免疫与上限实际生效。

## 12. 平衡复核重点

- 优先关注矢量防御在低熟练度时的可用性。`2:1` 会显著提高入门成本，需要用实战验证 75 CP 维持占用与动态伤害占用并存时是否过早耗尽 CP。
- 白金翼、跨越深渊、雷鸣、真空领域、解离射线等技能已有百分比或终结能力，熟练度奖励主要增强稳定性和战术性，不再直接放大特殊伤害。
- 区域传送、矿物探测、粒子云室和广域领域的范围增长会放大服务器开销，实现时应以总体积、已加载区块和每 tick 预算为最终硬上限。
- CP 返还统一设置触发间隔和单次上限，且返还不得再次触发熟练度经验事件，防止自循环。
- 新增控制效果不能覆盖统一免疫标签或第三方控制适配器的拒绝结果；玩家控制仍以服务端权威和可挣脱为前提。
