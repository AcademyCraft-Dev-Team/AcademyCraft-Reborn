# P.R.O.P.S 数值

所有普通获取仍乘以现有的获取系数；总因子上限为 2000。下表中的固定奖励跳过获取系数，仍遵循总量上限和因子锁定。

| 行为 | 基础获取 |
| --- | --- |
| 造成 1 点生命伤害 | 0.2 肌肉力量（包括玩家归属的能力、远程攻击，无旧单次 10 点上限） |
| 受到 1 点生命伤害 | 0.5 耐受力 |
| 恢复 1 点饱食度 | 0.5 耐受力 |
| 疾跑 1 格 | 0.004 灵巧度 |
| 游泳 1 格 | 0.01 灵巧度 |
| 跳跃一次 | 0.1 灵巧度，每 4 tick 最多一次；受限的跳跃不延后补发 |
| 拾取一颗经验球 | 0.1 感知力，与经验球的经验值无关 |
| 首次进入某个结构实例 | 固定 20 神经活跃度 |
| 治愈僵尸村民 | 20 神经活跃度 |
| 从炼药台取出一瓶药水 | 5 神经活跃度 |
| 合成一件白名单红石元件 | 5 神经活跃度 |
| 成功使用空白地图 | 5 神经活跃度 |
| 击败 Boss | 50 神经活跃度 |
| 首次击败远古守卫者 | 额外固定 100 神经活跃度 |
| 首次击败凋灵 | 额外固定 500 神经活跃度 |
| 首次击败末影龙 | 额外固定 300 神经活跃度 |

红石白名单：`data/academy/tags/item/props/neural_redstone_components.json`。
Boss 白名单：`data/academy/tags/entity_type/props/bosses.json`。
结构探索记录按玩家、维度、结构种类和起始区块保存。首次击杀记录沿用现有玩家存档。

| 因子 | 属性提升 |
| --- | --- |
| 肌肉力量 | 每 100 点 +0.5 近战伤害，线性部分上限 +6；800/1200/1600 点各额外 +1，总加成上限 +9；不再增加击退 |
| 耐受力 | 每 50 点 +1 最大生命值 |
| 灵巧度 | 每点 +0.1% 移速、+0.15% 跳高；800 点步高 +1，1200 点累计 +1.3 |
| 感知力 | 每 100 点 +0.1 抢夺、+0.1 时运 |
| 神经活跃度 | 每点 +0.01% CP 迭代速率 |

肌肉力量为 800/1200/1600/2000 点时，近战伤害加成分别为 +5/+8/+9/+9。旧存档中的肌肉击退修饰符会在玩家属性同步时自动移除。

跳高根据原版逐 tick 重力与阻力反算起跳速度。安全坠落距离同步增加，覆盖自身跳跃的最高点并向上取整；2000 灵巧度时安全坠落距离增加 3 格。

抢夺、时运与原有附魔叠加：整数部分固定生效，小数部分作为额外一级的触发概率。例如 100 感知力有 10% 概率额外 +1 级，1000 感知力固定 +1 级，1200 感知力提供固定 +1 级、20% 概率再 +1 级。感知力不再额外提高经验获取。

能力直接破坏、预先计算掉落、受控实体采集均使用施术者的感知力。新增能力可通过 `AbilityBlockDrops.getDrops` 计算提前生成的掉落，或通过 `AbilityBlockDrops.run/capture` 包裹完整破坏过程；不改变原掉落表、工具附魔、精准采集和空间存储行为。
