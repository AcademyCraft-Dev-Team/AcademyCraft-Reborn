# 精密操作：聊天文本分割与 Vec3 解析

两个节点接收字符串，可连接“本次聊天消息”“读取聊天记录”“文本常量”或字符串变量。

较大 GUI 缩放下，参数面板的端口列表会出现滚动条；将鼠标移入面板后滚动可查看其余端口。

## 文本分割

位于逻辑节点组。按所选规则分割，再输出指定片段。

| 参数 | 用法 |
| --- | --- |
| 模式 | 空白字符、换行、句末标点、自定义分隔符 |
| 分隔符 | 自定义模式使用完整原文，例如竖线、`::`、`→` |
| 片段序号 | 从 **0** 开始；可由输入端口覆盖 |
| 去除片段首尾空白 | 去掉每段开头和结尾的空白 |
| 忽略空片段 | 跳过空段，序号和数量以过滤后的结果为准 |

输出“文本”“数量”“存在”。序号越界时文本为空、存在为假；保留空片段时，合法的空段存在为真。

句末标点模式按 `。！？!?；;`、英文句号和换行分割，保留数字之间的小数点。换行模式兼容常见换行格式。自定义分隔符按整个字符串匹配，例如 `.*` 就匹配这两个字符。

## 文本转 Vec3

位于目标节点组。类型可选世界坐标、向量、方向；方向会自动归一化。

### 支持的格式

| 文本 | 含义 |
| --- | --- |
| `10 64 -20` | 三个数值，以空格或制表符分隔 |
| `10,64,-20` / `10，64，-20` | 英文或中文逗号分隔 |
| `(10, 64, -20)` / `[10 64 -20]` / `（10，64，-20）` | 成对括号 |
| `x=10 y=64 z=-20` / `X:10, Y:64, Z:-20` | 按 x、y、z 顺序命名 |
| `1.5 64 -2e1` | 小数、负数、科学计数法 |
| `~ ~1 ~` | 基准位置向上 1 格，仅用于世界坐标 |
| `~-1 80 ~2` | 相对与绝对轴混用，仅用于世界坐标 |
| `^ ^ ^5` | 基准局部坐标的前方 5 格 |
| `^2 ^3 ^5` | 局部左侧 2、上方 3、前方 5；三轴必须全部使用 `^` |

默认基准是施术者的**脚部位置和朝向**；可连接“参照实体”覆盖。世界坐标沿用基准实体所在维度。向量和方向使用 `^` 时只转换朝向，不叠加基准位置；它们不接受 `~`。

“整段解析”要求整个输入是一组三维数值，此时匹配序号应为 0。“提取匹配项”可从 `目标：(10,64,-20)，备用：(30,70,40)` 中选取第几组合法值，序号从 0 开始，也可用输入端口覆盖。

输出“结果”和“解析成功”。格式错误、没有指定匹配项、缺少必要基准、非有限数值或零向量转方向时，解析成功为假，且没有结果。请将“解析成功”接到条件分支，只在真分支使用结果；失败不会被替换成原点。向量与世界坐标可以为零。

## 示例：从聊天口令读取目标位置

聊天消息：`前进|^ ^ ^5|确认`

1. “收到聊天消息”设置关键词为 `前进|`，匹配方式为“以其开头”；消息来源按需求选“自己”或“所有玩家”。
2. “本次聊天消息”的文本连接“文本分割”。
3. 分割模式选“自定义分隔符”，分隔符填竖线，片段序号填 **1**。
4. 分割后的文本连接“文本转 Vec3”，类型选“世界坐标”。
5. “解析成功”连接条件分支；聊天触发的流程输出连接分支的流程输入。
6. 在真分支连接需要世界坐标的行动节点，并将解析结果接到目标位置输入。

此时位置是程序施术者前方 5 格；若要以其他实体为基准，将该实体连接到解析节点的“参照实体”。

## 边界

单次解析或分割最多处理 4096 个 UTF-16 代码单元；自定义分隔符最多 64 个。超长输入返回解析失败，或返回零个片段。聊天读取节点自身的长度限制仍然适用。

公共逻辑位于 `org.academy.api.common.ability.program.ProgramTextOperations`，可供其他能力模块复用。
