# 全技能效果、消耗、迭代与堆栈总表

本文按当前 `Skills.java` 注册表与服务端实现整理，共 **92 个已注册技能**。数据基线为 2026-08-19；“修改项”列特意留空，填写目标数值、公式或改动说明即可。

## 阅读规则

- `A`：能力强度倍率；`D`：玩家伤害倍率；`H` / `Hmax`：目标当前 / 最大生命；`Htmax`：目标真实最大生命；20 tick = 1 秒。
- “消耗”均为源码基础 CP。实际 CP 还会乘计算强度，并受熟练度档位、服务端配置、电流共生、未元物质六翼等修正。
- “迭代”是一次临时 CP 占用归还前所需的迭代点。默认每秒获得 1 点（需要 SP），所以 10 点基线约为 10 秒；永久占用只在关闭技能或效果结束后返还。
- 带施放 CP 或维持占用的技能，其 Builder 迭代声明会被 `MAX_CP_ITERATION_TICKS=20` 封顶。声明为 0 时，临时占用通常按 `ceil(基础消耗/2)` 推导。
- “有效堆栈（声明）”中，括号内是各技能 Builder 的声明值。当前 `STACK_LIMITS_ENABLED=false`，所以 Builder 堆栈限制的运行时有效上限都是 `∞`；矢量冲击的射线攻击按表中说明使用独立模式通道限制为 10 层，拉/推仍为 `∞`。
- 大多数技能在 1000 熟练度后，对相应类型的消耗应用 `×0.9`。呆然自失与印象操作的动态消耗档位为 `×1/0.9/0.8/0.8`；矢量反射与矢量偏移在 3000 熟练度时迭代由 10 降为 5。

## 统一修改时的实现入口

- 等级、基础 CP、维持占用、迭代和声明堆栈：各技能构造器的 `Skill.Builder`。
- 伤害、范围、持续时间、间隔和动态消耗：各技能类常量、计算方法及对应运行时管理器。
- 熟练度成本与迭代修正：`SkillProficiencyProfiles.java`。
- Mentalout 默认成本：`AbilityConfig.MentaloutSettings`；Aeromanip 还会读取其分类与单技能倍率配置。
- 全局堆栈是否生效：`Skill.STACK_LIMITS_ENABLED`。在重新启用前，需要先验证多重脑域分割的额外层数与所有动态占用路径。
