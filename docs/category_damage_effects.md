# 能力分类伤害与命中附效

本次方向取代“只接受提升”的常规伤害事件兼容。Academy 技能及分类伤害不向外部 LivingIncomingDamageEvent / LivingDamageEvent.Pre 征求数值，不接受这些事件的加伤、减伤、归零或取消。保留本模组的目标合法性、PVP/创造保护、护盾、反射、物质防御及输出控制；普通伤害仍经过原版护甲、附魔与吸收。特殊 actuallyHurt 与 CTA 改血路径保留，实际完成后继续发布不可变 Post 通知。

固定伤害与最大生命百分比继续分别记录。外部事件对两部分都无数值影响，输出控制额外提升只分配给固定部分。删除旧增幅探测命令、记录及合成事件。

## 实现接口

- `DamageComposition`：单次命中的固定/最大生命百分比边界。
- `SkillDamageSource.withElectricalChargePoints`：为主命中、回声、链式或子球指定电荷点数。
- `AbilityHitEffects`：公开的法则引爆、电荷、辐射和装备磨损方法，可被技能、精密操作及非玩家攻击复用。
- `ReactionSlowdown`：可关闭的共享减速租约；技能拥有其生命周期。
- `AcademyDamageRules`：内部防御与输出规则。新建内部伤害事件适配器时也应登记到此处。
- `CategoryDamageRuntime`：物理时钟过期、实际扣血回执、冷却所有权及分类附效。

玩家时钟复用已有服务端 tick/doTick 及客户端玩家缩放，网络保活、传送确认和连接维护保持正常频率。补齐动作 tick 门控及 2/3 浮点累积边界；实体场变化只重置对应目标的余数，不影响其他玩家。释放后不补发积压操作。
