01编辑器 · 形体与阶段

灰蓝色长盒是前臂尺寸的中性代理体。白质使用生产 VFXGraph 和真实 GPU 着色器，局部采样范围与游戏运行时一致。

沿用设计动作

分解向外抬起、错开并离析；修复由两端向中部接合，再压平收退。侧面图用于检查贴附和厚度。

保持局部尺度

长盒保留完整轮廓。切换“局部 2×”只是放大同一截图，原始文件与截图构图保持不变。

环境与相态对照

附带姿态、弱光和 β 相态画面。弱光参数属于编辑器固定输入，游戏夜景单独列在实机部分。

模型边界。编辑器长盒用于形体对照，玩家和生物实际模型请看游戏部分。局部表面代理不等同于任意模型的完整蒙皮采样，活体模型保留原有完整轮廓。

第一人称。修复使用手部镜头代理，白层完整位于视野内。该反馈没有采样当前工具的真实网格，不能据此推断白质精确贴合任意手持物的表面。

标准护甲。铁胸甲场景触发生命恢复的 BODY 反馈，同时核查普通铁胸甲的耐久未被修复。其用途是检查护甲外的可见性。

性能范围。记录提供几何规模、实例数量和清理结果。本画册没有独立 GPU 计时或 FPS 基准，不把截图中的帧率数字用作性能结论。
