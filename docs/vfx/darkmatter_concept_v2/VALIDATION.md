# 未元物质实现与验收记录

日期：2026-10-07。依据已确认的九技能方案开发，独角仙使用 Blockbench；根据追加反馈重新制作 VFX 羽毛材质。本页记录真实实现与验证，概念图仍独立保存在上级画册。

## 实现

16 张图覆盖九技能及抹消、接触、炮弹尾迹等辅助阶段。图参数、阶段曲线与输出可在内置 VFXGraph 编辑器调节。

| 技能 | 图与最终行为 |
| --- | --- |
| 创造／抹消 | `generation`／`elimination`；掌旁填充白羽物质片聚合或沿羽枝剥离，跟随实际储备变化，松键收束。 |
| 塑形 | `shaping`；成功后按提交形制与独立相态快照播放代理表面成形。 |
| 相态调谐 | `phase_tuning`；以厚度、间距与柔韧变化表达 α／β 配比，保持按键生命周期。 |
| 解构 | `disassemble`；实体／方块实际结算后播放局部剥离与完成碎屑。 |
| 切割 | `cut`；连续宽薄曲面与羽瓣尾缘，保留 γ 的延迟反向二斩。 |
| 干涉 | `interference`、`feather`、`light_contact`；图控制介质与公共方向场样式，服务端原双锥体继续决定范围。 |
| 修复 | `repair`；实际治疗／修复／净化成功后显示对应部位，合并连续脉冲。 |
| 创生 | `creation_summon`／`creation_dismiss`／`creation_contact`／`creation_trail`；真实召唤、销毁、命中与炮弹触发。稳定模型来自 Blockbench。 |
| 六翼 | `six_wings`／`wing_strike`；三对羽阵，接地时完整羽片保持脚部上方，飞行保留下压姿态；收展支持中途反向，第一人称降低遮挡。 |

所有图使用同族珍珠白羽毛材质：不对称宽肩、偏置灰羽轴、斜向羽枝束、根部柔灰、乳白尖端和薄透边。细羽枝按像素尺寸衰减，不依赖旧密集刷纹。创造／塑形取消空心生长环，抹消保留分层实体片；接触输出与当前半透明混合保持一致。

可复用能力位于公开 API：`FeatherArrayGeometry`、`MaterialFanGeometry`、`EffectAnchor`、`EffectScalarTransition`、`DirectionalFieldStyle`，以及 `feather_array`、`material_fan`、`output_material_surface` 节点。接口接受实体中立锚点、姿态／相态参数；六翼固定 132 粒子，重复更新不累计。旧粒子实例格式保留，新曲面独立追加法线。GPU 网格上传同时修复了 native 缓冲释放后仍返回其视图的问题。

Blockbench 正式源和 UI 原生导出见 [模型说明](../../models/darkmatter_creature/README.md)。113 个部位、320 个体块覆盖原有头／躯干／肢体／附加件分支，108 种组合由测试检查。运行时驱动六足步态、薄翼、鳍／尾扇、颚与炮口动作。

## 六翼追加更新与性能阶段

站立与飞行按完整羽翼根部到外羽尖核对夹角，两个间隔差不超过 3°。保留接地净空、飞行下压以及旧公开采样 API。

公开 `SurfaceOcclusionSampler` 与实体中立 `BlockSurfaceOcclusionSampler` 绑定到 `ActiveEffect`，资源重载保留绑定。每翼组使用三条碰撞射线，六组共享每世界 tick 最多 48 条的预算，边界缓存保存世界平面并随局部锚点转换；离屏停止查询。独立裁剪平面不占用物理法线，`block_penetration` 控制普通阻隔、灰透差分和完整穿透。

109 张真实 GPU 捕获成功；优化前后的 104 张同镜头图逐像素完全一致，新增捕获检查不同网格档位及连续混合实例段。`wings_block.init.gradle` 的真实客户端石墙验收通过：66／132 羽片取得接触边界，0／0.35／1 参数、移除方块恢复、停止后实例为零均检查成功。首次真实验收发现帧开始时清空可见性使查询停止，已修正为帧绑定读取前帧结果，更新锚点后发布当前结果，并重新通过验收。

多人优化增加公开参数缓存、按世界 tick 错峰的环境采样、有界稳定准入以及每效果独立的网格迟滞策略。透明实例按原顺序的连续档位分段绘制；零 alpha 剔除显式启用且默认关闭，旧实例格式与自定义材质契约保持兼容。遮罩仍逐帧更新，方向场合并等价双锥边缘计算，保留 32 次体积采样、强度、作用范围与真实命中流程。

阻隔预算的延后队列按实际观察到的 tick 批次保留优先级，低帧率跳过 tick 也不会长期饿死后面的翼组。200 批、108 组的专项检查覆盖每 tick 4 帧，以及每帧跨 2／5 tick，全部组持续获得查询且单 tick 不超过 48 条射线。

独角仙只重置动作涉及的部位和当前六足，保持近距动作等价；中远距使用公开距离策略及由正式 Blockbench 源派生的低模，保留关节名称、组合结构和原有剔除距离。服务端复用单次目标选择快照、直接召唤成员查询与可失效的蓝图 key 缓存，不降频 AI、导航、物理或命中。BB4／BB5 低模导出几何一致，108 组合回切及真实蓝图／所有者／NBT／迟注册扩展契约已检查。

固定场景的基线和性能更新结果已保存，分别见 [特效报告](runtime/performance/README.md) 与 [独角仙报告](../../models/darkmatter_creature/performance/COMPARISON.md)。特效最终 14／14 窗口通过，18 组六翼在 16／48／96 格的 GPU 中位耗时下降 21.2%／33.3%／40.0%，混合技能下降 12.9%。193／256 羽刃候选在 120 帧窗口内的新建图由 3860／5120 降至 0，停止图等待也归零；屏外实际绘制、三角形与上传均为零。干涉近中距和混合场的部分尾部耗时仍上升，完整结果保留，不宣称所有场景改善。

独角仙固定姿态批次均值中位数由 251.596 ns 降至 71.976 ns；真实 128 只、24 格场景的 CPU 渲染事件中位数由 6.804 ms 降至 5.712 ms。64 只／24 格的 GPU 回退保留。旧两轮 32 格摄影眼位位于原有 `packed_ice` 内，不能作为无遮挡低模收益证据；该数据原样归档，另外局部清空摄影点并检查真实眼位后补验。

压力测试使用单个真实客户端，分别标注 18 个中立视觉主体，以及八个 mock 网络通道服务端所有者的真实程序召唤实体；不将它们当作 18／8 个远程客户端。CPU、GPU 与服务器 tick 是整个固定场景成本，不直接解释成单技能／单只实体耗时或网络延迟。

最终石墙回归曾暴露摄影 fixture 的持久状态污染：独角仙摄影设置 `NoGravity=true` 后保存进复用存档，后续站立玩家的 `onGround=false` 导致下翼采用飞行姿态接触地板。已由 fixture 恢复真实重力并硬检查落地，未修改正式姿态或削弱断言；独角仙 fixture 也在结束时恢复原物理状态。重新验收空地 0、墙边 66／132、穿透差分、移墙 0、停止 0 全部通过；无遮挡 32 格补验检查真实眼位和结束后的玩家状态恢复，也已通过。

## 实现边界

图中的塑形成品与创生外壳是暂态代理；正式物品和实体沿用项目规则。场景干涉用明暗、散射与遮挡近似，不承诺真实折射、光线追踪或网格切割。

创生各部位 α／β 与 γ 的玩法快照保留；稳定模型的逐部位相态厚度插值尚未加入，外壳目前使用统一珍珠白。游泳验收在真实封闭水体中检查模型与动画；既有导航换实例时丢失 `canFloat` 的问题导致较快上浮，本轮未修改该玩法行为，具体原因与验证范围见客户端说明。

独立 GPU 捕获中的灰色人形和中性表面是明确的尺度／绑定 fixture，干涉主场、玩家锚点和独角仙动作以游戏截图为准。外部光影包的逐包人工观感复验尚未执行。
