# 未元物质多主体 VFX 性能验收

`DarkmatterPerformanceClientSmoke` 在一个真实开发客户端中，用 18 个真实追踪的中立 Cow 作为远端视觉锚点。六翼通过公开 `DarkmatterSixWingsVfxClient.attach` 接入，干涉范围和混合技能经服务端公开视觉 API 与实际网络包接入。该场景没有 18 个独立网络客户端，混合场景没有模拟实际技能输入或资源结算。191/192/193/256 羽刃场景使用真实客户端羽刃实体及生产适配器，测试有界静止位置重置，不验证服务端伤害。

14 个场景分别测量无特效的 18 主体、8/18 主体六翼、16/48/96 格六翼和干涉场、屏外六翼、多种效果并行，以及羽刃准入边界。每场预热 40 个客户端 tick，随后采集 120 个 CPU 提交时间和整帧 GPU 时间戳样本，测量期间不截图。CPU 时间从 `RenderFrameEvent.Pre` 到 `Post`，不包含全部游戏 tick 成本；GPU 时间包含本帧世界渲染、遮罩和特效。另列的帧间隔包含限帧与测量诊断，不能将其换算为无上限帧率。

固定配置为 1280×720、FOV 70、渲染距离 12、模拟距离 10、关闭垂直同步、120 帧上限、JetBrains Runtime 25.0.3。实测设备为 NVIDIA GeForce RTX 5070 Ti，OpenGL。

## 实现与复现

公开 `EffectParameterCache` 缓存适配器拥有的参数，图实例重载时重新绑定；`EffectUpdateCadence` 按世界 tick 采样，跨方块、换世界或时间回退即时失效；`StableEffectAdmission` 提供有界稳定准入、距离滞回、驻留时长与关键反馈优先级。适配器复用向量、四元数和矩阵，人体与掌部曲面变换每帧准备一次。六翼保留接地姿态、可编辑尺寸、局部阻隔与可控穿透；每个主体持有独立 `SurfaceDetailSelector`，完整 bounds 同源。

通用视觉图上限仍为 64，最多保留 512 份轻量有界状态，持续技能暂缓显示后保留时序；羽刃上限仍为 192。干涉样式快照只在成员、区域或样式变化时重建，场景遮罩仍逐帧接入。服务端协议、实际事件、计费、目标命中和接收者范围不变。

```powershell
$env:JAVA_HOME='C:\Users\Dusk\.gradle\jdks\jetbrains_s_r_o_-25-amd64-windows.2'
.\gradlew.bat runClientDev '-DisDev=true' -I docs/vfx/darkmatter_concept_v2/runtime/performance.init.gradle '-Dacademy.darkmatterPerformanceLabel=optimized'
```

相同标签会更新对应 JSON；最终轮更新 optimized 前需保留第一轮归档，不重写 baseline。最终实际九技能、details、field 和 wings_block 分别使用对应独立 init 脚本顺序运行，客户端自检通过和正常退出后才记作通过。单元测试、开发/发布构建与原生编辑器全图验收由统一验证记录汇总。

最终轮 18 六翼三个距离的 GPU 中位数均下降，实际三角形与上传量和第一轮一致；屏外仍零提交。18 干涉场三个距离的 GPU 中位数均低于 baseline，但 16/48 格的 GPU p95 仍分别高于 baseline，近、中距离 CPU p95 也上升。混合场 GPU 中位数下降 12.9%，CPU 中位数下降约 5.7%，CPU p95 从 6.257 增至 6.649 ms。第一轮与最终轮的收益幅度有差异；两个优化轮均原样保留，不挑选较快的一轮替代最终结果。

两个优化轮的四个羽刃场景全部维持零重建和零停止图等待；该确定性生命周期改进不能被解释为相同幅度的整帧 GPU 提升。场景没有增加独立网络客户端，未测端到端网络延迟或真实 18 客户端帧率。
