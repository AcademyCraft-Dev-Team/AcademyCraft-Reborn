## 共同材质与运动

主体是乳白、有质量的物质，内部用珍珠灰和羽轴纹理保留层次；边缘薄透，长羽片覆盖短羽片。高光只出现在少量边缘与接触峰值。避免把主体画成透明冰晶、霓虹电弧或浓白雾。

生成用聚拢，塑形用生长，调谐用密度与柔韧变化，解构用侵蚀剥离，切割用有方向的物质扇面，干涉用介质改变环境风与光，修复用局部贴面长合，创生用模块成形，六翼用三对翼的收展。目标轮廓、地形和准星持续可辨。

α／β／γ 是本项目的玩法分类。α 偏致密、厚实、有力，β 偏薄透、活跃和异常法则；γ 是六翼提供的独立增幅，不参与相态调谐，也不替换现有 α／β 配比。三者共用白色材质。

### 未元物质创造

主键持续生成 MP，副键持续抹消；用短促、局部的视觉反馈表现物质储备变化，松键立即收束。图中的核心属于短暂效果，不新增持久实体或物品。

生成逐渐聚拢；抹消从边缘剥落。亮度保持稳定，以密度和运动方向表达强弱。

VFXGraph 落点：新增 generation / elimination 图；共用薄片材质、掌部锚点、进度曲线。

图示边界：图中左右对照表示生成与抹消，不表示两种操作同时发生。

### 未元物质塑形

编辑器提交成功后只播放一次短促塑形反馈，成品按现有规则进入背包。剑、工具、方块等小样用于展示材质，远程武器、护甲等保持既有等级解锁。

成品使用独立的 α／β 快照；塑形不会自动改写玩家当前配比。11 种形制共用骨架生长与表面收平的语言。

VFXGraph 落点：新增 shaping 图，按形制绑定表面或保守代理；物品实体仍用现有模型。

图示边界：悬浮成品仅是概念阶段展示，落地时不增加永久工坊或漂浮装备。

### 相态调谐

持续按键把共享储备向 α 或 β 分配，松键结束。用羽片厚度、间距和响应速度显示配比，无新增伤害或投射物。

γ 是六翼的独立增幅储备，不参与本技能转换。相态都保持白色，避免靠颜色把能力拆成三套元素。

VFXGraph 落点：新增 phase_tuning 图；公开 density / flexibility / edgeActivity 等视觉参数。

图示边界：图的三组形态表示配比对照；γ 不在此图中。

### 未元解构

单次选中落点后同时表现实体和方块的实际结算。活体保持完整可辨，仅局部侵蚀；死亡或方块真实移除后才允许大面积散解。

α 偏物理解构，β 偏异常法则触发；标记引爆沿用共用的羽裂接触纹。

VFXGraph 落点：重做 disassemble 图；复用表面采样、erosion 与 smoke，增加分解完成阶段。

图示边界：不能把示意碎片当作真实网格切割；不出现持续射线或施术者到落点的光柱。

### 未元物质切割

主弧有明确的白色前缘、灰色内部和少量羽片尾缘，表现薄而有质量的切割面。γ 二斩保留现有 4–8 tick 延迟。

α 使形态更厚、更宽；β 强调薄刃和目标附着的羽裂纹；γ 二斩仍是同材质，靠反向与延迟区分。

VFXGraph 落点：迁移旧 SlashVfx 到图；新增通用物质曲面输出，短 Ribbon 只作尾部残影。

图示边界：图中两道弧属于相邻时刻叠示，不意味着无 γ 状态会同时二次命中。

### 未元干涉

α 是窄而有力的风暴和羽刃；β 是更广的环境光异常与侵蚀累积；γ 增加近身独立羽刃。原有服务端双锥体仍决定作用范围。

图下方三格是 α／β／γ 变体对照，不是三个按时自动转换的阶段。γ 在既有 α／β 上增幅。

VFXGraph 落点：以图控制方向场输出，复用公共 DirectionalFieldRenderer；羽刃、接触和主体生命周期都通过图调参。

图示边界：异常光不从眼睛或手掌发射。只承诺场景明暗与散射近似，不承诺光线追踪或真实折射。

### 未元修复

治疗、可见装备修复或负面状态缩短成功后才播放脉冲。身体、盔甲与手持物各有落点；仅背包物品变化时不伪造世界中的成品。

α 偏身体和装备修复，β 的净化表现为局部附着痕消退；γ 合并更多修复部位，保持总亮度上限。

VFXGraph 落点：重做 repair 图；继续使用部位遮罩、表面绑定、growth 材质和合并更新。

图示边界：补片是视觉设计，不承诺真实切开或修补实体网格。健康闲置时不维持全身强光。

### 未元创生

以白色独角仙作为材质与结构母题，覆盖步行、飞行、游泳躯干及近战颚、直射／追踪炮、感应器等模块。实际召唤仍遵守安全落点、4 个蓝图槽、最多 16 只与每只 40 CP。

各部位保持独立 α／β 快照；γ 催化沿用既有召唤时固化规则，不增加原作新生物设定。

VFXGraph 落点：新增召唤、解体、近战接触与炮弹尾迹图；稳定生物造型由现有蓝图实体模型承担。

图示边界：图中的模块小样用于造型方向，不代表本轮新增蓝图、攻击模式或任意网格输出。

### γ态·六翼

上对抬起、中对平展、下对下压，六个根部与尖端可辨。长初级羽覆盖短覆羽，翼面保留灰色分层和实物重量。开关状态沿用现有飞行、减伤、翼击与 γ 增幅。

翼面以姿态和羽片收展体现强度；不会把 γ 画成替换 α／β 的第三种颜色或限时终极爆发。

VFXGraph 落点：迁移旧六翼渲染入口；增加可编辑的通用羽片阵列／骨架形状输出，提供实体中立锚点接口。

图示边界：六翼输出已实现，见 `VALIDATION.md`。图的翼击与收回属于动作示意，必须实机校验六翼数量和第一人称视野。

## 共用接触与物质回收

异常法则标记统一表现为目标表面的稀疏羽裂纹，随累积增加少量重叠羽片；触发时在接触点开裂成短促白屑。羽刃命中只沿运动方向短暂穿出，保持当前单次伤害规则。实际 MP 回收可用极少白屑向身体侧边聚拢；掉落仍按现有物品吸附规则运动，不凭空新增资源。

## VFXGraph 与内置编辑器

全部新增视觉流程由 VFXGraph 组织，参数、阶段曲线、材质层与预览均在内置编辑器调节。底层复用公共渲染能力；创生的稳定实体造型和塑形的成品模型继续承担游戏实体与物品呈现。

现有图已支持发射器、运动曲线、实体／骨骼绑定、表面采样、半透明／发光层以及增长／侵蚀材质。Mesh 输出当前固定为立方体，导入网格主要用于采样；Ribbon 每粒子保留 8 个历史位置。因此六翼不能只靠修改现有 JSON 完成，长翼斩也不能直接承诺由短 Ribbon 还原。

已提供公开可复用的羽片阵列与骨架形状输出、物质曲面输出、图控制的方向场输出及视觉主体绑定（`FeatherArrayGeometry`、`MaterialFanGeometry`、`EffectAnchor`、`DirectionalFieldStyle`；`feather_array`／`material_fan`／`output_material_surface` 节点与 `six_wings` 图，见 `VALIDATION.md`）。接口接受实体、锚点、方向、形制与相态参数，避免硬编码玩家，为精密操作系统和非玩家实体复用预留入口。六翼、羽刃、翼击与构造生命生成层共用这些能力。

干涉现主场使用公共 DirectionalFieldRenderer，旧 darkmatter_interference 图仅保留历史预览。迁移时通过图参数控制这个公共输出，不误把旧图当作现行游戏主场。环境光改变采用明暗、散射与表面图案近似；真实背景折射、动态光照传播与网格切割不列入本轮承诺。

概念阶段编辑器离线；开发阶段重新启动内置编辑器，使用实际图加载、预览与游戏截图验收。上方九张概念图始终保留其概念图标识。

## 动作节奏与视野约束

短反馈建议以约 0.15–0.65 秒为初始调参范围，具体取决于接触、长合或剥离阶段。创造、调谐与干涉保持按键生命周期；修复与六翼保持开关生命周期。切割的 γ 二斩严格沿用现有 4–8 tick 延迟。画面的帧序与小样只表示动作方向，不新增玩法阶段。

第一人称只展示手部或侧缘的近场反馈，相机附近的羽片平滑衰减，背翼在相机内侧裁隐。连续修复与干涉复用实例；多人叠加按最终亮度和遮挡量验收。远距离减少覆羽、碎屑与烟层，保留轮廓及关键命中提示。

## 开发顺序与验收

1. 先完成共同羽片材质与可编辑形状输出，以六翼和切割验证主体轮廓，再扩展局部生长／侵蚀。
2. 制作创造、塑形、调谐，以及创生的召唤／解体和模块攻击反馈。
3. 重做解构、修复和羽刃／接触，接入图控制的干涉方向场与相态变体。
4. 在内置编辑器检查阶段、参数与热重载；在游戏内检查白天、夜间、室内、第一／第三人称、连续开关、目标失效、多人叠加和不同创生模型。
5. 完成相关生命周期与同步测试，运行 test -DisDev=true、开发与发布两种 build，以及 runClientDev 冒烟验证，再提供实机截图／录屏。

本轮实现与验证记录见本地归档 `VALIDATION.md` 与 `runtime/`（验收证据，不随仓库分发）。109 张 GPU 捕获使用项目真实渲染器，近距 104 张同镜头图在性能更新前后逐像素一致；九技能客户端流程检查实际结算与生命周期，干涉专项另检查遮挡、重载和场景清理。六翼夹角已协调，普通羽片遇实心方块局部收束，`block_penetration` 保留可控穿透。独角仙与多主体特效的测量条件、对照数据和回退场景见各自性能报告。外部光影包的逐包观感尚未人工复验；概念图始终保留概念图标识。
