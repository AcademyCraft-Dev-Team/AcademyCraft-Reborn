# 黑翼多人优化实施结果

日期：2026-09-07。基线提交：`08e63fbf6b5234e4b83accea8f6ce91ba72bcbb2`。

已实施[方案](D:/mcmodtest/AcademyCraft-Reborn-26.2/docs/vfx/black_wings/multiplayer_optimization_plan.md)中 A–C 的核心代码，并完成自动测试、实际客户端渲染检查及开发/发布构建。独立服务器上多个真实客户端的限速联机、GPU 定时和长时间内存验收尚未完成，不据此宣称全部建议指标已达成。

## 已实现

- **连续播放**：攻击携带激活周期、序号和固定落点。客户端使用暂停时冻结的本地单调时钟，普通事件从第一次可见提交开始播放 0.8 秒；不再用跨端世界 tick 差提前结束动作。每实体仅保留当前与最新待播两招，正常连续边界沿用上一招结束时间，最多承接 50 ms 帧余量，避免逐招积累计时误差；重复序号忽略，突发包合并，待播超过 1 秒清理。实体未到允许等待 500 ms，最多 256 个状态。停用、退出、死亡和世界切换清理，迟加入观察者接收当前状态快照。激活附件延迟不会永久取消有效周期。
- **采样与网格**：同一分支共享主轴、切线、旋转和宽度缓存；非网格点保持精确求值。管网格直接写入可复用的大缓冲，去掉逐曲线直接内存分配和二次合并复制，缓存环截面。仍保持核心→细流→高光顺序及真实断开的镂空拓扑。
- **多人预算**：先按完整羽翼/攻击包围范围剔除，再模拟几何。近中远逐级减少细流、轴向段、圆周段和墨屑；本机优先保留完整细节，总量同时限制为 120,000 顶点及 8 MiB/帧。最低档为前 16 名候选预留四翼容量；更大人数压力下可跳过低优先级效果。不可见时停止采样，0.75 秒后释放效果状态，重入使用当前视觉时钟。
- **网络与移动**：攻击发送给本人和已追踪观察者；无逐帧动画包。飞行方向合成一个输入意图，由服务器每 tick 推进一次，收包仅更新意图。持续输入每 4 tick 心跳，按键变化或朝向变化 1° 立即发，同 tick 封顶一次；10 tick 断流转 KEEP。速度纠正保留每 tick 一次。白翼/白金翼仍走原控制入口。

五招顺序、每招 16 tick / 0.8 秒、约 20% 蓄势、肩根弯曲轮廓、近景左 14/右 10 条细紫高光及小镂空保持。四翼仍落向施放位置四周四角；服务器费用、冷却、即时扇形伤害判定保持。

通用时间线、输入意图/邮箱和渲染预算均置于 `org.academy.api`。渲染缓存与流式网格接口可供其他效果和编辑器复用。

## 离线性能对比

同一 JVM、同一 JSON、旧实现取自上述基线提交。每项预热 40 帧、测量 80 帧，四翼相位固定 0.52、墨流时间连续变化。包含实际采样、建管网格及合并；不包含世界坐标变换、GPU 上传执行、片元绘制、角色渲染及网络。八人新方案为一名完整本机效果加七名受预算控制的远端效果，因此八人收益同时包含缓存/缓冲优化与 LOD。

| 情况 | 旧/新 CPU 中位数，ms | 旧/新 CPU P95，ms | 旧/新每帧网格字节 |
| --- | ---: | ---: | ---: |
| 单人待机 | 2.177 / 0.917 | 3.548 / 2.679 | 2,316,672 / 2,316,672 |
| 单人四翼 | 8.982 / 2.504 | 10.285 / 2.714 | 4,633,344 / 4,633,344 |
| 八人待机 | 14.950 / 2.220 | 20.329 / 2.596 | 18,533,376 / 4,048,032 |
| 八人同时四翼 | 66.641 / 5.269 | 71.075 / 5.550 | 37,066,752 / 7,017,504 |

八人四翼几何处理中位数降低约 **92.1%**，要求提交的网格字节降低约 **81.1%**，该探针路径的堆分配中位数从 14,955,328 降至 22,128 字节/帧。堆分配不含直接内存；网格字节是渲染数据，**不是网络流量或实测 PCIe 带宽**。不能把此表解释为游戏 FPS 提升。

单人四翼采样中位数为 1.846 ms，满足原方案的 2 ms 目标；八人同时四翼总 P95 为 5.550 ms，不能宣称已经达到“八人混合距离正常连招总 P95 ≤4 ms”的完整实机目标。GPU 参数化升级是否必要仍需 GPU/真实联机指标。

全精度采样对照覆盖五招与待机、分支、不同进度/时间以及网格和非网格点，测得最大位置差 **0.0 m**。完整数据：[multiplayer_optimized_comparison.json](D:/mcmodtest/AcademyCraft-Reborn-26.2/docs/vfx/black_wings/multiplayer_optimized_comparison.json)。原始探针源码、旧类副本及执行日志在被 Git 忽略的 `build/black_wing_analysis`，清理 build 会删除它们。

## 验证

- `./gradlew test -DisDev=true`：1763 个测试，0 失败、0 错误、0 跳过。涵盖 30/59/144 FPS 各连续 300 招不累积帧误差、长渲染中断、迟到事件、抖动连招、重复/突发包、有界队列、快照序号、控制心跳/断流、16 人四翼预算、镂空网格及现有五招轨迹。
- `./gradlew runGameTestServer -DisDev=true -PacademyGameTests=academy:wing_network_motion`：通过。实际服务器玩家按 10 种方向组合 × 3 种俯仰角 × 2 种初始速度比较旧/新移动推进，结果一致。
- `./gradlew build -DisDev=true` 与 `./gradlew build -DisDev=false`：通过。
- `./gradlew runClientDev -DisDev=true --init-script tools/vfxgraph-editor/scripts/black-wing-client.init.gradle`：通过。单人五招完整播放；随后通过嵌入式连接加入 8 名受驱动的 `ServerPlayer`，让实际客户端接收追踪、附件、状态与攻击包并渲染，合计播放 40 招，重复/合并/过期均为 0。转开视角时可见数及几何预算降为 0，转回后恢复 8 个效果；移除实体后清空。

上述八人检查是**一个真实客户端观察八名辅助服务器玩家**，不等于八个真实客户端的网络验收。测试入口仅属于 editor 源集，不进入 mod JAR；测试世界位于独立的 `run/black-wing-client/saves/black_wing`。该入口需要预先存在同名测试世界，不会自动修改普通游戏存档。逐阶段诊断保留在本地 `build/black_wing_analysis/client_smoke.log`，不纳入 Git。

## 部署与剩余验证

客户端和服务端必须同时更新。黑翼攻击、控制注册键分别升级为 `black_wing_attack_v2`、`black_wing_control_v2`，增加 `black_wing_state_v1`；不要混用旧包格式。发布包是当前整个工作区构建，包含工作区原有的其他修改；本轮没有编辑这些无关文件，已逐一校验其哈希不变。

本机视觉仍等服务器确认后开始，网络 RTT 引起的点击前等待尚存在；不应与开始后的动画卡顿混淆。未启用本机预测或 GPU 参数化改造。

实施参数与方案初稿的差异：非网格主轴采用精确缓存求值，避免插值改变已有轮廓；LOD 采用 15% 滞回和稳定细流子集，尚未加入 100 ms 拓扑过渡。大于 250 ms 的本地渲染中断按有界队列到期/合并处理，尚未加入初稿提出的 80 ms 姿态混合。正常连续渲染的 0.8 秒时长不变。

仍需独立服多客户端的 RTT 100–400 ms、抖动/限速/短时断流、边飞边打、晚加入和切维度复测；还需固定分辨率 GPU 定时与 10 分钟资源/内存循环检查。这些项目尚无实测结果，不能以单测或辅助玩家替代。
