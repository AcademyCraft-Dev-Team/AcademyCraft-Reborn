# 未元干涉：范围泛光与空气散射方案

状态：已实施。实现、实机截图、性能测量和验证记录见 [验收记录](darkmatter_interference_field/README.md)。下文保留设计依据。

## 目标画面

未元干涉开启后，杀伤区域内可见的方块表面与实体出现乳白色受光和柔和泛光，保留原本的纹理、阴影与模型细节。站在区域外观察时，空气中沿环境光方向排列的疏密光带显露出受影响区域的形状、开角与射程。进入区域后，空气层平滑减弱，表面提示保留。

光带方向取环境主光方向；区域的朝向仍由技能瞄准决定。这样可以看到“自然光穿过被干涉的区域”，而不会把区域误画成沿玩家视线发射的一束白光。普通干涉取消现有稀疏空中羽片与六个地面光斑作为范围主体；保留独立命中反馈和六翼／追猎羽刃。

## 范围必须来自实际判定

当前 `DarkmatterRadiation.Server.pulse` 使用 α、β 两个圆锥角域与球形距离上限的并集：α 通常更窄更远，β 更宽。熟练度、六翼及技能射程倍率影响最终射程，视线包含俯仰角。现有 `DarkmatterVisualPacket` 只同步一个最大射程，不能准确复原这个并集。

1. 抽取可复用的方向性作用区域数据，保留两个分支各自的最终射程和 `minimumDot`，以及权威眼位、视线方向、施术者、维度和更新时间。
2. 服务端伤害判定与视觉同步使用同一份计算结果，客户端只做表现。不能根据相位权重是否为零自行隐藏分支：现有 α／β 伤害公式均包含基础伤害。
3. 方块表面逐像素判断世界位置是否在区域内；范围穿过大方块表面时只覆盖界内部分。
4. 现有 `ViewTargetScanner.Cone` 按实体包围盒**中心点**判定。实体沿用此规则选中，然后覆盖它的可见模型，避免出现“脚已亮但中心尚未进入杀伤范围”的误导。原有敌对过滤仍决定伤害；友方与物品等位于范围内的实体也可获得范围泛光，泛光本身不表示已造成伤害。
5. 目前范围扫描没有地形视线阻挡条件。本次不增加墙体挡伤害的规则；画面始终遵守观察者的场景遮挡，不透视墙后的表面或实体。

## 第一层：可见表面白色泛光

使用完整分辨率的场景深度重建可见表面的世界位置，计算作用区域遮罩。区内叠加略带珍珠灰层次的乳白受光，并把受限强度的发光量写入现有 `GlowEffect`。

- 不更换方块贴图、不把材质刷成纯白，保留原色与暗部。日间、夜间都能读出边界，夜间降低总亮度。
- 边界从区域内向边缘约 0.15–0.30 格平滑过渡，范围外不额外扩大覆盖。泛光晕允许很轻的屏幕扩散，不用于判定实际边界。
- 使用缓慢、低对比度的明暗变化表达光受到干涉；取消连续高频闪烁。
- 实体需要独立的可见模型遮罩，使用中心点选择结果及正常场景深度测试，不能只用包围盒替代模型。未选中的实体也须从地形覆盖中排除，避免其表面因逐像素范围测试而产生错误亮斑。
- 主深度只足以处理正常写入深度的地形与实体。玻璃、水和透明实体需补材质感知的遮罩绘制，并沿用原材质透明度／裁切，不能宣称一个深度后处理就覆盖了全部透明表面。
- 天空、HUD、第一人称手持物不参与范围覆盖。显示范围外的前景实体应正确遮住区域内的表面和体积光。

## 第二层：范围外可见的空气散射

在同一作用区域内做有界的体积采样。每条观察射线先求与范围包围球的交段，再将终点截到场景深度；只有交段内且满足 α／β 任一分支的采样点贡献散射。

- 使用沿主光方向拉长的低频噪声，形成宽窄交错、内部有间隙的白色光带。光带可以穿过整个区域，但发光量严格受技能范围裁切。
- 边缘靠散射密度的变化显露，不添加不透明外壳、线框或硬白色圆锥。
- 白天使用太阳方向；室内与夜间保留较弱的范围散射以便读懂作用区。第一版只近似局部环境亮度，不声称追踪了每个火把或窗孔的实际光路。
- 从区域外侧、后侧和高处观察都应能辨认大致轮廓，不将可见性全部绑定到强烈的前向散射角度。
- 相机进入范围后，按相机的区域距离连续降低空气密度，初始目标为区域外的 15%–25%；离开后连续恢复。不会通过 F5 模式硬切换，也不会全屏白闪。
- 多个干涉场先合并或限幅散射和覆盖强度，避免同一区域被重复加白。

这是表现丁达尔效应观感的体积散射近似，不是物理光线追踪。观察者深度遮挡和主光方向必须正确；真实光源阴影属于后续增强，不能用同屏深度冒充光源阴影。

## 管线与性能

| 部分 | 实施位置与职责 |
| --- | --- |
| 公共范围数据 | `org.academy.api.common` 下提供方向性区域及包含测试，技能产生最终参数。 |
| 服务端 | `DarkmatterRadiation` 复用区域结果做扫描与同步；保留命中、资源和羽毛结算。 |
| 同步与生命周期 | 扩展干涉视觉状态的两个范围分支和方向；沿用开始／更新／停止、维度及超时清理。 |
| 地形与实体遮罩 | 新增独立范围渲染通道；地形用深度重建，实体及透明物体补模型／材质遮罩。 |
| 表面与散射着色器 | 共用区域函数，分别输出表面覆盖与空气散射；与现有 `GlowEffect` 合成。 |
| 客户端调用 | 利用 `MixinLevelRenderer` 已有世界后处理时序，世界绘制完成后、HUD 和手部之前处理。 |
| VFXGraph | 保留 `darkmatter_light_contact` 与羽刃；干涉范围主体由场景着色通道承担。 |

深度通过独立副本采样，避免同时读写同一附件；复用项目已有逆投影处理，并识别 reversed-Z 与 `isZZeroToOne`。GPU 资源随分辨率重建，停止、世界切换及客户端关闭时释放。

表面遮罩保持完整分辨率，空气散射初始使用半分辨率与 24–32 次采样，再按深度边缘上采样。先做视锥／距离裁剪和屏幕包围区域限制；无干涉场时完全不运行该通道。根据实际 GPU 测量设置场数量和采样预算，不用截短真实范围来降低开销。

## 验收

1. 检查纯 α、纯 β、混合相位、熟练度及六翼倍率下的侧边与射程上限，含向上／向下瞄准；用边界内外测试点对照服务端判定。
2. 在暗色、亮色方块、台阶／楼梯、透明玻璃、水和不同实体上检查覆盖、纹理保留及深度遮挡。实体进出范围按中心点变化，实际命中另有短促反馈。
3. 固定同一场，从区域外侧、后侧、上方、内部与第一人称截图；展示相机进出时空气密度连续变化，准星附近目标仍清晰。
4. 白天、夜晚、室内、多人重叠、大范围和快速转向分别检查；原来的稀疏羽片不再承担边界展示。
5. 验证停止、断更、死亡、切维度及图／资源重载后不残留；记录 1080p 开关前后的帧耗时，再完成单测、相关 GameTest 与开发／发布双构建。
