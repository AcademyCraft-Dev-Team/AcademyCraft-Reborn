# 能力与技能使用说明

本文整理能力开发机当前可展示的能力与技能用途，目标是作为后续 GUI 技能详情文案的内容基准。

- 快照日期：2026-08-09。
- 覆盖范围：以 `Skills.java` 当前实际注册的技能为准。
- 内容优先级：当前服务端实现与测试高于语言文件中的旧文案。
- 本文专注“如何使用、产生什么效果”；伤害公式、CP 公式、迭代周期与平衡风险见 [SKILL_BALANCE_MATRIX.md](SKILL_BALANCE_MATRIX.md)。
- 技能按键可在设置中修改，因此 GUI 描述应使用“施放键”“切换键”“按住并松开”等动作，不写死默认按键。

## GUI 文案建议

1. 技能未学习时也应显示用途说明，放在技能名称/等级之后、开发条件之前。
2. 正文可直接沿用本表“建议用途说明”，对应本地化键 `skill.academy.<技能 ID>.desc`。
3. 技能名称、推荐等级、操作形态、开发条件和消耗应由数据分别渲染，不重复塞进描述正文。
4. 描述优先说明操作、目标、核心结果和关键限制；内部公式、调试术语与实现类名不进入玩家文案。
5. “占用 CP”表示技能开启期间会降低可用计算力；“消耗 CP”表示每次施放或生效时支付计算力。

## Level 0 / 公共脑域

通用课程技能自动生效，没有独立施放按键。熟练度档位为 0/1000/2000/3000 对应 1/2/3/4；重置能力分类时保留这些技能。

| Lv | 技能 | 操作形态 | 建议用途说明 |
| ---: | --- | --- | --- |
| 1 | 脑域开发 `level0_passive_lv1` | 常驻被动 | 最大 CP 提高 `熟练度档位 × 能力等级 × 5`。 |
| 1 | 耐力训练 `endurance_training` | 常驻被动 | 耐受力提高 `熟练度档位 × 50`。 |
| 1 | 体术训练 `physical_training` | 常驻被动 | 肌肉力量与灵巧度分别提高 `熟练度档位 × 25`。 |
| 2 | 多重脑域分割 `level0_passive_lv2` | 常驻被动 | 所有有限堆栈技能的堆栈上限提高熟练度档位。 |
| 3 | 思考并列演算 `level0_passive_lv3` | 常驻被动 | CP 迭代速度提高 `熟练度档位 × 5%`，与技能调试加速乘算。 |
| 4 | 意识完全解析 `level0_passive_lv4` | 常驻被动 | 每点 SP 可迭代的 CP 提高 `熟练度档位 × 10%`，满档为 14 CP/SP。 |
| 5 | 自我绝对控制 `level0_passive_lv5` | 常驻被动 | 免疫 CP 归零后的过载状态。 |
