# 本地结构批量归块与树冠静止归块修复

## 指令

需要 `/academy debug` 的管理员权限，可由玩家或服务端控制台执行：

```text
/academy debug sublevel restore_all
/academy debug sublevel restore_all status
/academy debug sublevel restore_all cancel
```

第一条以存档中各维度的本地 SubLevel 清单建立快照，逐个归块，包含未标记的旧结构、静止或悬空结构，以及玩家未加载位置的结构。以当前所在地回正为竖直、最近的 90° 整数倍朝向；不送回最初提取位置。后续新生成的结构不加入正在执行的快照，可以再次运行。每个服务器同一时间只执行一个任务。

`status` 显示已处理、已归块、已消失、保留、等待事务恢复数量，以及至多八条保留原因和位置；完整保留清单写入服务端日志。已被其他操作移除的结构单列为“已消失”，不算指令归块成功。`cancel` 停止后续处理并释放本任务的区块票据；已经提交的持久事务仍继续恢复。服务器停止也会释放票据，重启后需要重新运行未完成的批次。

指令只枚举本项目的本地 SubLevel 清单，绝不把 Sable 结构放进队列。安装 Sable 的存档若还保存有本地结构，会启动本地运行时维护这些历史内容；新的技能捕获后端仍由原路由选择。航空学等模组的 Sable 结构不受这个指令或 ACR 自动归块影响。

## 边界和保护

批量任务最多同时持有一个结构所需的 64 个宿主区块票据，使用独立、非持久票据类型，不移除地形缓存自己的票据。等宿主方块与实体数据完成加载后才放置；实体读取异步发起，不把尚未读完的数据视为空。每次完整尝试间隔五 tick，单个候选等待不超过 200 tick；同一 tick 不会批量写入多个结构。

管理员通道不要求技能来源标记、在线所有者或自然落地，可以清理未模拟的本地结构；仍保留正在捕获、控制、交互或事务恢复中的结构。它不补造技能来源。清理沿用已有持久事务：先保存目标并持久提交，随后清源并释放容量。未标记源的事务也可在重启后恢复。

“所有”表示扫描所有本地清单条目，不能理解为无条件覆盖方块或删除内容。下列项目安全保留并报告：

- 目标无可用空位、存在实体/其他结构、越界或保护事件拒绝。
- 方块实体/容器、流体、内部实体、超过 256 个非空气方块或 32,768 格扫描范围的内容。
- 所属维度未安装/不可用、源加载失败、区块预算或等待时限耗尽。
- 正在使用或尚未完成的捕获/归块事务。

不产生掉落物来替代失败归块，不覆盖树叶、草或其他世界方块，不丢弃容器。含容器结构需保留其原有交互方式处理；指令不会声称已归块。实际管理员来源仍经过放置权限和事件校验；控制台不伪造玩家。

`StructureRestorationEvent` 新增 `cause()`、`actor()` 和 `provenance()`。管理员请求的 cause 为 `ADMINISTRATIVE_REQUEST`；对未标记结构，`provenance()` 为空，兼容 getter `metadata()` 可为空。保护插件应使用 Optional 判定，不能假定每个事件都有技能 owner。旧自动归块事件仍具有真实创建元数据。指令本身的权限不能通过公共 `StructureGridRestoration.request` 指定 cause 绕过。

## 树叶/台阶上的归块

修复了两处限制：

1. 原支撑扫描只看碰撞盒 AABB 最低点附近，还排除了更高的障碍物表面。倾斜长条由较高一端搭在树冠/台阶上时，合法接触会漏检。现在沿实际有向碰撞盒的完整高度作预算内扫描，以向下扫掠命中的朝上接触法线确认支撑；侧墙、悬空和深度重叠仍被拒绝。
2. 原归块仅尝试一次质心对齐。倾斜结构回正后可能与树冠重叠，即使原物理姿态没有冲突也会无限重试。现在仅在固体碰撞占位时向上寻找最近空位，最多八格；保持所有方块相对布局和朝向。非碰撞占位（例如 LIGHT）、流体和方块实体不会触发这一让位策略。目标仍必须全为空气、满足生存条件且无实体或其他结构。

自动归块仍只处理明确的 ACR 技能创建标记，仍检查连续静止和真实支撑，仍不主动加载区块；上述加载能力仅属于显式管理员批量指令。

## 验证

实机夹具使用 `run/native-sublevel-direct-smoke*` 隔离存档。`canopy` 检验真实解算器上四格铁条落到阶梯树叶后，由正式调度自动归块，并验证客户端碰撞清除和容量可复用。`admin` 通过真实指令分发器检查跨维度、未加载位置、未标记/已标记/未模拟内容、树叶让位、权限、取消、保护事件、容器保留和重复执行；Sable 环境另检查外部未标记 Sable 对照结构未被修改。

`admin_crash_targets_saved`、`admin_crash_commit_saved` 在未标记本地结构归块的真实持久检查点中断测试进程；随后 `recover_verify` 检查恢复后只有一个内容所有者。这些中断代码仅在测试 source set，不包含在发布包中。

最终命令、结果、构建包与未验证项见 `validation/native_structure/structure_restore_all_validation_2026_10_24.json`。
