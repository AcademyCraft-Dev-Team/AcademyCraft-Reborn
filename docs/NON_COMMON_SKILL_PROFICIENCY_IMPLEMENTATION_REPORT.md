# 非通用技能熟练度实现与验收记录

## 实现结论

本轮已按 `NON_COMMON_SKILL_PROFICIENCY_PLAN.md` 完成非通用技能熟练度的代码和资源覆盖：87 个非通用技能均有显式熟练度声明，1000、2000、3000 三档中英文说明各 261 条，且已由注册表覆盖测试和本地化完整性测试约束。

自动化单元测试及开发/发布双构建通过。当前尚未关闭的验收项有两类：Mentalout 路径与 AI 相关 GameTest 在重复运行间存在非确定性失败；各能力类别的客户端及双玩家人工游戏内验收仍需在可交互客户端中执行。

## 基础设施

- 保留原有 750/1500/2250 技能等级计算，熟练度里程碑统一由 `SkillData.getReachedProficiencyThresholds` 计算为 0～3 档。
- `Skill` 提供玩家熟练度、里程碑、单次/持续/维护/动态消耗及迭代间隔查询；`SkillContext` 保存施法时熟练度与里程碑快照。
- `SkillProficiencyProfile` 与 `SkillProficiencyProfiles` 统一声明技能倍率、迭代覆盖和无标量配置原因。
- 消耗顺序统一为“基础值和专项值 → 熟练度倍率 → 全局计算强度”。飞行弹体、光束、放置场和延迟效果使用施法快照；切换技能和被动维护实时读取并重算占用。
- `TimedSkillEffectRuntime` 统一管理有容量限制的标记、冷却、二次伤害、治疗/护甲修正等临时状态，并在死亡、退出、实体离开世界和服务器停止时清理。
- 服务端策略包含总开关、采矿束精炼、区域传送变换/交换、心理掌控扩展控制、区域最大边长 40、捕获弹体上限 16、单次附加实体上限 96；有效策略会同步到客户端。
- 玩家技能偏好可持久化保存，并通过服务端校验的数据包修改。
- 技能开发器显示当前档位、已解锁效果、下一级/未来效果及服务端禁用状态。

## 分类别实现摘要

### 矢量操控

- 矢量反射和矢量偏移共用有限伤害、CP 检查、部分抵消和开发模式处理逻辑。
- 两者伤害 CP 倍率均为 `2/1/0.5/0.5`。计算强度为 1、伤害为 10 时，四档消耗为 `20/10/5/5 CP`。
- 两者迭代间隔均为 `10/10/10/5`；矢量偏移基础间隔已由 40 调整为 10。
- 已接入反射过滤、冲击波、矢量之翼和等离子体等技能的档位效果；原维护占用保持不变。

### 气流操控

- 气流场及相关弹体/放置效果保存施法里程碑快照。
- 已实现范围、持续时间、滑翔、弹体捕获、友军继承等档位效果，并以已加载区块和服务端实体上限约束搜索。

### 电击使

- 已实现能量溢出、矿脉分组、高阶护盾、标记/连锁和电球分裂等档位效果。
- 矿脉处理仅使用已扫描且已加载的位置，不主动加载新区块。

### 原子崩坏

- 射线与残留场保存施法快照。
- 已实现辐射传播、精炼掉落、残留效果和自动目标等档位能力，精炼受服务端策略和玩家偏好共同控制。

### 暗物质

- 已实现自动修复、护甲/标记、甲虫群体行为和“六翼”跨技能数量限制。
- 自动修复同时受玩家设置和服务端有效策略控制。

### 空间移动

- 已实现返回锚点、物品暂存、载具层级保护、连续闪现队列和空间切除边界效果。
- 区域传送支持显式选择旋转、镜像及交换模式，并校验熟练度和服务端策略。
- 事务会快照并变换方块、方块实体、流体、计划刻、实体位置/朝向及载具关系；失败时回滚。
- 仅允许同维度、已加载且互不重叠的区域；实体数量受服务端上限约束。传送实体获得 2 秒坠落伤害保护。

### 心理掌控

- 已实现名单链式控制、目标重选、深度昏睡、入侵控制、感知残像和编队路径等档位效果。
- 3000 档玩家控制扩展仅开放数字热键切换快捷栏和副手使用，服务端校验会话、序列、熟练度、策略和频率，并禁止借此访问容器。
- 精密操作图序列化升级至版本 4，3000 档允许一次双分支无环条件判断；旧图可迁移，低熟练度提交分支节点会被服务端拒绝。

## GameTest 现状

最近一次 `gradlew runGameTestServer -DisDev=true` 共执行 23 项，20 项通过、3 项失败：

- `academy:mentalout_cube_mob_path_and_cube_damage`
- `academy:mentalout_direct_flying_mobs_path`
- `academy:mentalout_impression_strict_hostility_chain`

重复运行时失败名称会在既有 Mentalout 路径、飞行单位、守卫反应和敌对链测试间变化，说明当前不是稳定的固定基线。新增加的 mixin、协议和区域计划刻访问器均能正常完成 GameTest 服务端启动与注册，但在稳定复现并消除 Mentalout 非确定性之前，GameTest 门禁不能标记为完全通过。
